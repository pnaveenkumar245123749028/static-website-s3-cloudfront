About Me

Bridging resilient cloud infrastructure design with modern, accessible frontend development.

I am an aspiring Cloud and Software Engineer passionate about designing secure, resilient, and performant cloud architectures. My engineering journey centers on building reliable solutions that eliminate single points of failure, minimize attack surfaces, and optimize delivery performance.

Route 53 DNS Resolution

Handles global low-latency domain name resolution using AWS Anycast network.

  • ✔Custom domain maps directly to CloudFront using an Alias (A) record.
  • ✔Zero query charges when routing queries to AWS CloudFront distributions.
  • ✔Seamless health checks and failover routing capabilities.
